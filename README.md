# 🏏 IPL Data Analysis

An exploratory data analysis project on IPL match data using Python.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Project Overview

This project analyzes IPL match data to identify patterns and insights
related to teams, players, toss decisions, match results, venues, and
other match-level statistics.

## 🔍 Analysis Performed

- Team-wise match performance
- Toss analysis
- Toss decision vs match result
- Most successful teams
- Player performance
- Venue-wise analysis
- Match-winning trends
- Data visualization

## 📈 Visualizations

The project contains multiple graphs and charts created using
Matplotlib and Seaborn.

## 🚀 How to Run

1. Clone this repository
2. Install the required Python libraries
3. Open `IPL_Capstone_Project.ipynb`
4. Run the notebook cells
